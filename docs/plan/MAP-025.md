## Implementation Strategy
1. Extract draft models first (no behavior change)
2. Extract handlers one by one (CreatePoint → Drawing → Location → FeatureClick)
3. Update Executor to delegate to handlers
4. Update MapStoreFactory to wire handlers

- Risk: DI complexity increases
  - Mitigation: handlers injected via MapStoreFactory constructor
