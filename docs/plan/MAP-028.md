## Implementation Steps

### Step 1: Add .editorconfig
```ini
root = true

[*]
charset = utf-8
end_of_line = lf
indent_style = space
indent_size = 4
insert_final_newline = true
trim_trailing_whitespace = true

[*.{kt,kts}]
indent_size = 4
max_line_length = 120

[*.gradle.kts]
indent_size = 4

[*.xml]
indent_size = 2

[*.json]
indent_size = 2
```

### Step 2: Add versions to libs.versions.toml
```toml
[versions]
ktlint = "12.1.0"
detekt = "1.23.6"

[plugins]
ktlint = { id = "org.jlleitschuh.gradle.ktlint", version.ref = "ktlint" }
detekt = { id = "io.gitlab.arturbosch.detekt", version.ref = "detekt" }
```

### Step 3: Add plugins to build.gradle.kts
```kotlin
plugins {
    // ... existing plugins
    alias(libs.plugins.ktlint) apply false
    alias(libs.plugins.detekt) apply false
}

subprojects {
    apply(plugin = "org.jlleitschuh.gradle.ktlint")
    apply(plugin = "io.gitlab.arturbosch.detekt")
    
    ktlint {
        android.set(true)
    }
    
    detekt {
        config.setFrom("$rootDir/config/detekt/detekt.yml")
        buildUponDefaultConfig = true
    }
}
```

### Step 4: Create detekt.yml
```yaml
complexity:
  LongMethod:
    threshold: 60
  LongParameterList:
    threshold: 6
  LargeClass:
    threshold: 200

style:
  MaxLineLength:
    maxLineLength: 120
  NewLineAtEndOfFile:
    active: true
```

### Step 5: Run and fix violations
```bash
./gradlew ktlintCheck
./gradlew detekt
# Fix all violations
```
