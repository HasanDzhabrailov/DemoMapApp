# Plan - MAP-026

## Summary
Split `MapRenderStyleAppliers.android.kt` into focused applier files by feature responsibility.

## Affected Modules
- `composeApp/androidMain` → `feature/map/render/`

## Target Structure
```
feature/map/render/
├── MapRenderStyleAppliers.android.kt   (removed)
├── PointStyleApplier.android.kt        (~60 lines)
├── LineStyleApplier.android.kt         (~70 lines)
├── PolygonStyleApplier.android.kt      (~80 lines)
├── RulerStyleApplier.android.kt        (~55 lines)
├── DrawingPreviewApplier.android.kt    (~120 lines)
├── CurrentLocationStyleApplier.android.kt (~40 lines)
└── StyleApplierConstants.android.kt    (~30 lines)
```

## Implementation Strategy
1. Create `StyleApplierConstants.android.kt` with shared IDs
2. Extract one applier at a time with its layer/source IDs
3. Update `MapRenderer.android.kt` imports if needed
4. Delete original file after all extractions complete

## Risks and Mitigations
- Risk: Import breakage after split

- Risk: Helper functions duplication
  - Mitigation: Keep `closedRing`/`toGeometryPoint` in `PolygonStyleApplier` (primary user) or create internal helpers file
