# Plan - MAP-019

## Summary
Migrate line and polygon drawing workflows into Store-first MVIKotlin architecture while reusing existing draft updater, preview mapper, and shape creation use cases.

## Affected Modules
- `feature/map/api`
- `feature/map/impl`
- internal map store package
- `feature/map/ui`
- `feature/map/render`

## File-Level Plan
- Route drawing callbacks through Store intents
- Move drawing mode and draft ownership into Store state
- Reuse existing helpers where appropriate:
  - `ShapeDrawingDraftUpdater`
  - `ShapeDrawingPreviewMapper`
  - `CreateMapLineUseCase`
  - `CreateMapPolygonUseCase`
- Move confirm-time shape creation orchestration into executor
- Keep current renderer mapping path intact as much as possible

## MVIKotlin Mapping
- Intent:
  - start line drawing
  - start polygon drawing
  - add position
  - remove last position
  - open details
  - update shape title
  - confirm shape creation
  - dismiss drawing
  - dismiss create-shape sheet
- State:
  - `drawingMode`
  - `shapeDrawingDraft`
  - `isCreateShapeSheetVisible`
- Reducer:
  - start/reset drawing
  - update draft vertices
  - update title
  - show/hide details sheet
- Executor:
  - invoke line/polygon creation use cases
  - handle confirm-time orchestration
- Label:
  - likely unnecessary unless needed for a transient output

## Migration Strategy
1. Inventory current drawing workflow in component
2. Route drawing actions through Store intents
3. Move pure draft transitions into reducer
4. Preserve gating rules for details opening
5. Move final creation use-case invocation to executor
6. Keep preview/render mapping stable
7. Verify user-visible drawing behavior remains unchanged

## Verification
- `./gradlew :composeApp:compileDebugKotlinAndroid`
- `./gradlew :composeApp:compileKotlinJvm`
- `./gradlew :composeApp:test`

## Risks and Mitigations
- Risk: minimum-vertex gating changes unintentionally
  - Mitigation: keep explicit rules for line=2, polygon=3 and test them
- Risk: draft reset behavior changes after create/dismiss
  - Mitigation: test create success and dismiss separately
- Risk: preview rendering diverges from draft state
  - Mitigation: keep preview mapper contract stable during this ticket

## Task Breakdown

3. Move drawing state transitions into reducer
4. Preserve details gating logic
5. Move line/polygon creation to executor
