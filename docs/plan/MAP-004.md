# Plan — MAP-004

## Summary
Introduce one render-owned input model and one pure mapping step from feature state to renderer input, while preserving current behavior and keeping MapLibre Android-specific.

## Affected Modules
- `feature/map/api`: keep screen/business-facing state only
- `feature/map/impl`: add or host the pure adapter mapping step
- `feature/map/ui`: invoke adapter and pass render-owned model into renderer
- `feature/map/render`: own the renderer input contract and keep `expect/actual` entrypoint
- `androidMain` map renderer actual: consume render-owned input and keep MapLibre URL resolution local
- `jvmMain` map renderer actual: consume render-owned input for placeholder rendering
- `root/api`: no change expected
- `root/impl`: no change expected
- `root/ui`: no change expected

## Implementation Notes
- Add a minimal render-owned model such as `MapRenderModel`
- Keep the render model typed and small; do not pass `MapState` through it
- Add a pure mapper from feature state to render model
- Keep mapper free of Compose, Android, and MapLibre APIs
- Update `MapRenderer` to accept the render-owned model only
- Keep style URL resolution inside Android render code only
- Avoid broad renames or package churn

## Risks
- Product semantics and render semantics may get duplicated if style ownership is not chosen carefully
- Adapter logic may drift into the composable if the seam is not explicit
- The render model may become a copy of feature state if it is not kept intentionally narrow

## Verification
- `./gradlew test`
- `./gradlew :composeApp:compileKotlinJvm`
- `./gradlew :composeApp:compileDebugKotlinAndroid`

## Task Breakdown
1. Add a render-owned input model in `feature/map/render`
2. Add a pure adapter mapping step from feature state to render model
3. Change `MapRenderer` expect/actual contract to the new render model
4. Update `MapScreenContent` to invoke the adapter and pass render-owned input only
5. Keep Android style URL resolution in Android render code only
6. Verify behavior and compilation remain unchanged
