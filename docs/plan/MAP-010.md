# Plan - MAP-010

## Summary
Add a minimal controls overlay to the map screen with:
- a settings button
- a popup menu
- bottom-right zoom controls

Keep shared UI and state in `commonMain`, keep actual zoom execution in Android MapLibre code only, and keep `GPS` as a UI-only placeholder for a future ticket.

## Affected Modules
- `feature/map/api`
- `feature/map/impl`
- `feature/map/ui`
- `feature/map/render`

## File-Level Plan
- Extend `MapScreenComponent` with settings menu state, placeholder toggle state, and a one-shot viewport command
- Update `DefaultMapScreenComponent` to manage menu/toggle/zoom intents
- Add shared Compose overlay UI for:
  - settings button
  - settings popup menu
  - zoom controls
- Update `MapScreenContent` to render the new overlays
- Extend `MapRenderer` expect/actual API with optional viewport command support
- Implement Android zoom execution in `MapRenderer.android.kt`
- Update JVM renderer stub to accept the new API
- Add or reuse a settings icon resource from shared resources
- Add tests for menu, toggles, and zoom command state
- Run minimal verification

## Architecture Notes
- `MapScreenComponent.Model` owns UI state only
- Zoom is not persistent UI state; it is a one-shot renderer command
- Renderer receives only the minimal command needed to adjust camera zoom
- Renderer does not own settings menu state or placeholder business behavior
- MapLibre camera behavior remains Android-only
- `GPS` in this ticket is a placeholder presentation flag only
- Future current-location behavior must be introduced in a separate ticket through a dedicated abstraction in the feature implementation layer
- No location, permission, or current-position business logic may be added to the menu composables or the renderer in this ticket

## Proposed Command Model
- `MapViewportCommand.ZoomIn`
- `MapViewportCommand.ZoomOut`

## Interaction Rules
- Opening settings menu closes center marker menu
- Opening settings menu closes selected feature info window
- Opening center marker menu closes settings menu
- Clicking a map feature closes settings menu
- `Доступные карты` closes menu
- `Карты на экране` closes menu
- `GPS` and `Рулетка` toggle without closing menu
- `GPS` does not request permissions, locate the user, or move the camera
- Outside tap closes menu and should not leak through to map interactions

## Android Zoom Execution
Preferred implementation:
- Use built-in MapLibre camera update functions such as `CameraUpdateFactory.zoomIn()` / `CameraUpdateFactory.zoomOut()` with `MapLibreMap.animateCamera(...)`

Fallback:
- If helper APIs are unavailable in the current SDK surface, use a standard camera update based on the current zoom and adjust by one step through MapLibre camera APIs
