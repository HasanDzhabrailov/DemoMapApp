# Plan - MAP-020

## Summary
Migrate feature selection and info window behavior into Store-first architecture. Reuse existing resolver and mapper helpers, but move ownership of the workflow from the component to explicit Store boundaries.

## Affected Modules
- `feature/map/api`
- `feature/map/impl`
- internal map store package
- `feature/map/ui`
- `feature/map/render`

## File-Level Plan
- Route renderer-driven feature click path into Store intents
- Keep UI translation layer minimal if it still needs to bridge renderer click models
- Reuse existing helpers:
  - `MapFeatureSelectionResolver`
  - `MapFeatureInfoWindowStateMapper`
- Move selection/orchestration into executor where feature lookup is treated as workflow logic
- Move pure open/close state transitions into reducer

## MVIKotlin Mapping
- Intent:
  - feature clicked
  - dismiss feature info window
- State:
  - `selectedFeatureInfoWindow`
  - any intermediate selection state only if required
- Reducer:
  - clear selection
  - commit resolved feature info window state
  - close conflicting overlays if that remains a pure state rule
- Executor:
  - resolve clicked feature from `MapState`
  - map selected feature to info window state
- Label:
  - not expected unless needed during transition

## Migration Strategy
1. Inventory current selection/info-window flow
2. Route feature clicks through Store intent
3. Move feature resolution/mapping orchestration into executor
4. Move resulting UI state transitions into reducer
5. Preserve current overlay interaction rules
6. Verify shared info window behavior remains unchanged

## Verification
- `./gradlew :composeApp:compileDebugKotlinAndroid`
- `./gradlew :composeApp:compileKotlinJvm`
- `./gradlew :composeApp:test`

## Risks and Mitigations
- Risk: overlay-closing rules change unintentionally
  - Mitigation: preserve current conflicting-overlay behavior explicitly
- Risk: feature lookup fails for some types
  - Mitigation: keep resolver reuse and type coverage tests
- Risk: renderer click bridge becomes more complex than needed
  - Mitigation: keep UI translation minimal and push ownership into Store
