# MAP-028 — Add Quality Automation: ktlint, detekt, editorconfig

## Context
The project lacks automated code quality checks:
- No `.editorconfig` for consistent formatting
- No `ktlint` for Kotlin style enforcement
- No `detekt` for static analysis
- No CI integration for quality gates

This leads to:
- Inconsistent code formatting across files
- No automated detection of code smells
- Manual code review overhead for style issues

## Goal
Establish baseline quality automation for consistent code style and static analysis.

## Non-Goals
- No custom ktlint rules (use default)
- No CI integration in this ticket
- No detekt custom rules
- No baseline file generation

## Functional Requirements
- Add `.editorconfig` with Kotlin/Android defaults
- Add ktlint Gradle plugin with default rules
- Add detekt Gradle plugin with recommended config
- Add Gradle tasks: `./gradlew ktlintCheck`, `./gradlew detekt`
- Fix all violations found by initial run

## Acceptance Criteria
- [ ] `.editorconfig` exists with Kotlin defaults
- [ ] `./gradlew ktlintCheck` works without errors
- [ ] `./gradlew detekt` works without errors
- [ ] All existing code passes checks

## Constraints
- Follow `AGENTS.md`
- Use default ktlint rules (no customization)
- Use detekt baseline configuration
- Keep changes minimal

## Success Metrics
- `./gradlew ktlintCheck` exits with 0
- `./gradlew detekt` exits with 0
- IDE formatting matches ktlint rules
- Code review no longer checks for style
