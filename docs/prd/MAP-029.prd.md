# MAP-029 — Add ktlintFormat task for auto-formatting

## Context
MAP-028 established ktlint for code style checks, but developers need to manually fix style violations.

## Goal
Add `./gradlew ktlintFormat` task to auto-format code according to ktlint rules.

## Non-Goals
- No CI integration in this ticket
- No changes to ktlint rules

## Functional Requirements
- Verify ktlintFormat task works correctly
- Document usage in AGENTS.md or README
- Ensure formatted code passes ktlintCheck

## Acceptance Criteria
- [ ] `./gradlew ktlintFormat` works without errors
- [ ] Documentation explains when to use ktlintFormat
- [ ] Running ktlintFormat then ktlintCheck passes

## Constraints
- Follow AGENTS.md
- Keep changes minimal

## Success Metrics
- Developers can auto-format code before commit
- Reduced style-related code review comments
