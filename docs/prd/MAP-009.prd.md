# MAP-009 — Remove map debug panel and related dependencies

## Context
The map feature currently contains a `MapDebugPanel` overlay with dedicated debug state in the screen contract.

This panel is no longer needed and should be removed completely.

`lastCameraSnapshot` must remain in the screen model because it is required by the existing center-driven point, line, and polygon flows.

The change must stay minimal and local to the map feature.

## Goal
Completely remove `MapDebugPanel` and all related dependencies while preserving existing map creation, rendering, selection, and info window behavior.

## Non-Goals
- No changes to `lastCameraSnapshot`
- No changes to point, line, or polygon flows
- No changes to `MapRenderer`
- No changes to `MapLibreCameraAdapter`
- No redesign of map UI
- No broad refactor outside the map feature

## Acceptance Criteria
- [ ] `MapDebugPanel` is fully removed
- [ ] `composeApp/src/commonMain/kotlin/ru/tech/demomapapp/feature/map/ui/MapDebugPanel.kt` is deleted
- [ ] `MapScreenComponent` no longer exposes `debugModel`
- [ ] `MapScreenComponent` no longer exposes `onDebugPanelToggle()`
- [ ] `MapScreenComponent.DebugModel` is removed
- [ ] `DefaultMapScreenComponent` no longer contains debug panel state or toggle logic
- [ ] `MapScreenContent` no longer subscribes to or renders the debug panel
- [ ] Preview implementation matches the updated `MapScreenComponent` contract
- [ ] `lastCameraSnapshot` remains intact
- [ ] No references remain to `MapDebugPanel`, `DebugModel`, `debugModel`, or `onDebugPanelToggle`
- [ ] Existing point, line, polygon, preview, and info window behavior remain unchanged

## Constraints
- Follow `AGENTS.md`
- Keep the change minimal and within the map business area
- Keep Compose UI-only
- Keep MapLibre Android-specific
- Do not place business logic in renderer code
- Respect KMP-first architecture

## Success Metrics
- The map screen no longer shows the debug panel
- The map feature compiles without debug panel dependencies
- Existing center-driven flows remain unchanged
- Minimal relevant verification passes
