# MAP-025 - Decompose MapStore Executor by responsibility

## Context
`MapStoreExecutor.kt` (369 lines) handles too many responsibilities: point creation, drawing (line/polygon), feature click, location/GPS, and ruler orchestration. This violates single responsibility and creates a growing god-class as features are added.

`MapStore.kt` (293 lines) contains Intent/Message/State/Label/Model classes in one file, which is compact but the Executor is where growth occurs.

## Goal
Split `MapStoreExecutor` into focused handler classes, keeping Intent/Message/State/Label inside `MapStore.kt`. Each handler owns its feature area's side effects and collaborates via Executor orchestration.

## Non-Goals
- No changes to Store interface/State/Label definitions
- No changes to Intent/Message structure
- No behavior changes to existing features
- No Executor->Router orchestration introduction

## Functional Requirements
- Extract `CreatePointHandler` for point creation logic
- Extract `DrawingHandler` for line/polygon creation
- Extract `LocationHandler` for GPS/location logic
- Extract `FeatureClickHandler` for feature selection
- Keep `MapStoreExecutor` as thin dispatcher/orchestrator
- Intent/Message/State/Label stay in `MapStore.kt` (compactness)
- Draft model classes may be extracted to `model/` subfolder

## Acceptance Criteria
- [ ] `MapStoreExecutor` reduced to ~120 lines (thin dispatcher)
- [ ] Handler classes own their feature's side effects
- [ ] All existing tests pass
- [ ] No behavior changes to GPS, ruler, point/line/polygon creation, feature click
- [ ] Handler injection via MapStoreFactory

## Constraints
- Follow `AGENTS.md`
- Class-based handlers (not extension functions)
- Handlers own side effects (use cases, time, id generation)
- Executor remains the message/label dispatcher
- Preserve test coverage

## Success Metrics
- Executor is describable as "thin dispatcher"
- Each handler is describable with one responsibility
- Future features can add handlers without touching Executor
- MapStore.kt remains a compact MVI definition file
