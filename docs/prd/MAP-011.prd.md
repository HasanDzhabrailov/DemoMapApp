# MAP-011 - Add one-shot current location flow and my-location button

## Context
MAP-010 added the map controls overlay, zoom controls, settings popup, and a placeholder `GPS` toggle.

The map still has no real permission handling, no current-location lookup, and no dedicated always-visible "my location" button.

This ticket introduces real one-shot current-location behavior separately from MAP-010 and must preserve existing menu, zoom, compass, center-marker creation flows, and shared feature info behavior.

## Goal
Add real one-shot current-location behavior to the map screen with:
- a real `GPS` toggle in the existing settings menu
- a separate always-visible left-side "my location" button
- a dedicated current-location marker rendered separately from user-created points
- a manual placeholder "my location" mode when GPS is off

## Non-Goals
- No continuous tracking
- No follow-my-location mode
- No background/service/foreground-service logic
- No location history or persistence
- No MapLibre location component integration
- No changes to ruler behavior
- No redesign of MAP-010 menu, zoom, or compass behavior
- No broad refactor outside the map feature
- No changes to point, line, polygon, or feature info product behavior beyond minimal overlay coordination
- No requirement in this ticket to choose a final long-term Android location backend beyond a minimal one-shot implementation

## Functional Requirements
- Keep the existing `GPS` item inside the settings popup menu
- Add a separate always-visible left-side "my location" button
- The "my location" button remains visible regardless of GPS state

- When `GPS` is turned on:
  - start a one-shot current-location request flow
  - check permission before reading device location
  - request permission only if needed
  - if permission is granted and location is resolved, show the current-location marker on the map
  - if permission is granted and location is resolved, move the camera to that location once
  - if permission is denied or location cannot be resolved, keep GPS mode off and show no current-location marker

- When `GPS` is turned off:
  - turn GPS mode off
  - hide the current-location marker
  - clear any active manual placeholder mode

- When the "my location" button is pressed while GPS mode is active:
  - start a one-shot current-location request flow
  - update the current-location marker when location is resolved
  - move the camera to the resolved location once
  - do not start continuous tracking

- When the "my location" button is pressed while GPS mode is not active:
  - do not request permission
  - do not use real device location
  - if a camera snapshot is available, switch to manual placeholder mode
  - place a placeholder "my location" marker at the current map center
  - if no camera snapshot is available yet, do nothing

- Manual placeholder mode is temporary screen state only
- Enabling GPS mode clears manual placeholder mode
- The current-location marker must be rendered separately from user-created map points
- The current-location marker must not open the shared feature info window
- MAP-010 menu, zoom, and compass behavior must remain intact
